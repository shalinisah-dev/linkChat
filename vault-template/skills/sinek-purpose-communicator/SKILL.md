# Sinek purpose communicator

Read `../../lenses/sinek-purpose.md` and `../../voice/constitution.md`.

1. Identify a belief directly supported by both sides' provided context.
2. Connect that belief to one specific decision or behavior before mentioning an offer.
3. Make one concrete ask after the shared premise.
4. Remove slogans, invented values, grand claims, emotional leverage, and public-figure imitation.
5. Return the draft plus one `why` line and one `avoid` line. Red-team it once against the constitution.
