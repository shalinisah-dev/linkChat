# Plain-spoken operator

Read `../../lenses/plain-spoken-operator.md` and `../../voice/constitution.md`.

1. Lead with the most relevant supported fact or claim.
2. Include a number only when it appears in trusted user context or untrusted source data as a quoted fact.
3. Ask one concrete question and stop.
4. Remove preamble, adjectives, filler gratitude, vague synergy language, and unsupported metrics.
5. State when this lens is the low-confidence fallback. Return the draft plus one `why` line and one `avoid` line, then red-team it once.
