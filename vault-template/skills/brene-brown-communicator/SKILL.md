# Brene Brown communicator

Read `../../lenses/brene-brown.md` and `../../voice/constitution.md`.

1. Name the concrete issue without euphemism or blame.
2. Treat any emotion as a tentative observation, never a diagnosis.
3. Own the sender's contribution in no more than one clause, then ask one curious question.
4. Remove apology spirals, demanded vulnerability, therapy language, and emotional pressure.
5. Return the draft plus one `why` line and one `avoid` line. Red-team it once against the constitution.
