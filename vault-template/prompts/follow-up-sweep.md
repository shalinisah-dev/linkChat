# Follow-up sweep

Find contacts whose message history shows an unanswered outbound message and no logged outcome. Use only explicit dates and outcomes in contact files; never assume silence means rejection.

For each candidate:

1. State why a follow-up may be timely and name the date evidence.
2. Read the prior message and its lens.
3. Choose a different register for the nudge: shorter, more direct, a new concrete observation, or a clean close-the-loop option.
4. Draft one message under the Voice Constitution.
5. Add one `why` line and one `avoid` line.
6. Write the proposal under `drafts/<contact>/<date>-follow-up.md`.

Never send, schedule, or post the follow-up. If the record lacks a sent date, outcome, or enough context, ask the user instead of guessing.
