# Evidence-backed messaging playbook

This file starts empty. Add a hypothesis only when at least three independent cases support it.

Each hypothesis must record:

- Scope: objective and relevant high-confidence recipient signals
- Pattern: the narrow delivery choice being tested
- Support count and case IDs
- Counterexample count and case IDs
- Confidence: low, medium, or high
- Last tested date
- What would falsify it

Never turn a single success into a rule. Never promote a hypothesis into `voice/constitution.md` without explicit user approval.
