# Plain-spoken Operator: direct control

## Fit

Use for time-poor or analytical recipients, and as the fallback when all Recipient Read signals have low confidence.

## Moves

- Make one supported claim.
- Include one number only when the provided context contains it.
- Ask one concrete question.
- Remove preamble, adjectives, and performative warmth.

## Guardrails

Do not mistake brevity for bluntness. Do not invent metrics or compress away essential context. State when this is the low-confidence fallback.

## Transformations

- Padded: `I hope you're doing well. I wanted to reach out because...` -> `You cut three features to improve retrieval. Did that change roadmap adoption?`
- Vague: `Would love to explore synergies.` -> `We solve the same retrieval bottleneck from different sides. Worth a 15-minute comparison?`
